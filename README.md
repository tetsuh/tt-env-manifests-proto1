# tt-env-manifests-proto1

Stack and OS manifests consumed by [`tt-env-proto1`](https://github.com/tetsuh/tt-env-proto1).

- `releases/<release>.json` — Stack Manifests (component versions)
- `manifests/<os_id>-<os_version>.env` — OS Manifests (package mappings)

This repository is **private** for proto1.
